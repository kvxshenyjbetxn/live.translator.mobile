# Live Translator Mobile

Переклад звуку з вибраного застосунку українською в реальному часі. Для Android 10 і новіших версій.

## Встановлення

Завантажте APK з [останнього релізу](https://github.com/kvxshenyjbetxn/live.translator.mobile/releases/latest) та встановіть на телефон.

## Як користуватися

1. У **Налаштуваннях** введіть власний API-ключ Google Gemini та збережіть його.
2. На головному екрані виберіть застосунок, звук якого хочете перекладати.
3. Натисніть **Почати переклад** і надайте запитані дозволи Android.
4. Увімкніть звук у вибраному застосунку. Зупинити переклад можна в перекладачі або через сповіщення.

## Важливо

- Потрібні інтернет і доступ до Gemini API; діють умови та ліміти Google.
- Звук передається Google для перекладу. Застосунок не зберігає аудіозаписи; API-ключ зберігається на телефоні без шифрування — не діліться ним.
- Не всі застосунки дозволяють захоплення звуку або відображаються у списку.
